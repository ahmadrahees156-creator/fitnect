# FitNect — Athlete Wellness & Injury Risk Monitoring

FitNect is an athlete wellness and fitness platform designed to help users monitor daily wellness, track workouts, understand recovery, manage nutrition and hydration, and gain insights into potential injury risks.

The platform combines a modern web application with backend APIs and machine learning capabilities to support more informed training and recovery decisions.

## Features

- **Personalized Dashboard:** View fitness and wellness information in one place.
- **Workout Library:** Explore workouts and training exercises.
- **Nutrition Tracking:** Search foods and monitor calories, protein, carbohydrates, and fats.
- **Personalized Nutrition Targets:** Generate nutrition targets based on user profile information.
- **Hydration Tracking:** Monitor daily water intake.
- **Daily Wellness:** Record wellness information and monitor trends.
- **Recovery Tracking:** Understand recovery status and training readiness.
- **Injury Risk Awareness:** Identify potential risk patterns using workload and wellness indicators.
- **Training Insights:** Review fitness information to support training decisions.
- **User Authentication:** Access personalized features through an account.

## Development Workflow

The team works in a shared repository with separate branches for each development domain.

- `frontend` — React web application
- `backend` — Server-side APIs
- `ml` — Machine learning and data science
- `mobile` — Mobile application

Each team member commits changes to their own branch and works within their designated folder. Changes should be reviewed, tested, and integrated into the main branch after integration.

## Project Goals

- Make athlete wellness information easier to understand.
- Encourage balanced training and recovery.
- Support nutrition and hydration awareness.
- Provide useful insights from fitness and wellness data.
- Explore machine learning for injury-risk awareness without treating predictions as medical diagnoses.

## Disclaimer

FitNect is a fitness and wellness support project. Injury-risk estimates and training insights are informational and should not replace professional medical advice or assessment.
